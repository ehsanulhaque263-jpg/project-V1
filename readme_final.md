# Traffic Violation Registry System

**Course:** CSE115L  
**Section:** 7  
**Semester:** Fall 2026

## 1. Project Description

The Traffic Violation Registry System is a menu-driven C programming project designed to manage traffic violations and vehicle-related records. The system allows users to access vehicle information, identify traffic violations, calculate fines, and manage payment records.

The main purpose of this project is to simplify the process of maintaining traffic violation records and tracking unpaid fines. It provides an organized and user-friendly interface through which users can perform different operations.

## 2. Features

- **User Login:** Provides a login system to restrict access to the application.
- **Interactive Menu:** Displays different options and allows users to navigate through the system.
- **Vehicle History:** Allows users to view the violation history of registered vehicles.
- **Violation Type and Fine:** Displays different types of traffic violations and their corresponding fines.
- **Unpaid Fine List:** Displays records of unpaid traffic fines.
- **Fine Payment:** Allows users to access the payment option and manage fine payment records.
- **Payment Deadline:** Provides information about payment deadlines for traffic violations.
- **Exit System:** Allows users to safely exit the application.
